產品功能介紹

從品牌 Reveal 到架構圖完整建立，約 60–90 秒。結束於「Powering the Enterprise Agent.」
Brand Identity 4 Pillars Reveal Feature Breakdown Architecture Stack Corporate Keynote Tone
腳本摘要與段落目的
腳本原文節錄 ASUS Enterprise Agent Platform
Intuitive Agent Experience · Token Efficiency · Enterprise Security
→ 四大優勢展開（各含 2 個 sub-feature）
→ One Integrated Stack：Cloud / Model / Agent Infra
段落目的
建立「這是一個可信、完整、有深度的 Enterprise AI 平台」的印象。邏輯是：品牌錨點 → 承諾（4大優勢）→ 證明（各優勢細節）→ 技術底氣（架構圖）。觀眾看完這段應該知道「這個平台有哪四個價值主張，底層如何運作」。
視覺基調
深色底 + Aurora 漸層（藍→紫→青）。每一幕都是在「疊加一層」，傳達「建設感」。整體節奏偏沉穩有力，不快，每個 beat 都有停頓呼吸感。類比：Google Cloud Next 開場 keynote 的節奏感。
色彩情緒
深藍（信任）+ 紫調（AI/未來感）+ 白色文字（清晰）+ 金/藍強調（品牌感）。避免太多顏色，保持高級感。
關鍵動畫時刻 · AE Keyframes
  • ASUS logo + Aurora 光暈從中心浮現，背景漸層微動
  • 三個 tagline 以 0.3s 間隔依序 stagger 飛入（Y -12px + fade）
  • 標題消退，四個圓形 badge 從中心出現
  • 四卡片依序 Shape Morph：圓 → 矩形展開，icon Trim Path 描線
  • 切換至各 Pillar 細節：sub-feature 逐行 bullet stagger in
  • Cost-Efficient：Odometer 數字滾動展示 Token 節省量
  • Secure：Shield icon 描線 + 節點亮起保護網
  • Powerful：多 Runtime badges 從四方飛入，連接線 draw-on
  • 架構圖：三層由下往上 build-up，漸層連接線生長
  • Camera pull-out 顯示全圖，標題「Powering the Enterprise Agent」
整段 easing: Bezier 0.4, 0, 0.2, 1 (Material Standard) 場景切換: Light Sweep, 0.5s 背景微動: wiggle(0.3, 6) on gradient hue 總時長建議: 65–80s

第二段 · 案例一

MyAgent — The Intuitive Agent Experience

從技術描述轉向「使用者體驗」的展示，以真實 UI 操作畫面為主角。約 30–45 秒。
Browser + Canvas UI Cursor Interaction IM Trigger Token Management Workspace & Skills
腳本摘要與段落目的
腳本功能列表 Secure Zero-Install Cloud · Intuitive Visual Experience
Unified multi-tool interface · Seamless Agent-Human Collaboration
Integrated Workspace & Skills · 24/7 Proactive IM Command & Control
Cost-Efficient Operations
展示指示 Show browser & canvas & Workspace & Skills
IM Trigger → Token 管理 → AgentPod Service 引出
段落目的
從「平台能做什麼」轉向「使用者每天怎麼用它」。重點在於「直覺感」——畫面應該讓觀眾覺得「這個工具用起來很自然」，而不是「功能很多很複雜」。情感目標：信任 + 想要馬上試用。
視覺基調轉換
從第一段的「暗底建構感」轉向偏亮、偏白的 UI 主導感。類比：Apple 產品 Demo 的風格——UI 是主角，背景退後。游標移動要有人性化的速度感（不能太快、不能太慢）。
敘事結構建議
建議用「一個完整的使用情境」串連七個功能，而非逐條列出。例如：一個員工打開 MyAgent → 看到 Workspace → 發出 IM 指令 → AI 回應 → Token 計數出現 → 完成任務。這樣比單純的功能列表更有說服力。
關鍵動畫時刻 · AE Keyframes
  • MyAgent 標題 + tagline fade in，背景從深藍過渡到較亮的 UI 調性
  • Browser frame 從螢幕中央 scale-in 出現（帶微陰影）
  • Canvas + Workspace 佈局在 browser 內展開（panel 依序 slide-in）
  • 游標緩慢移動到 Skills 圖示，hover ring 出現，tooltip 浮現
  • 左側 IM 窗格出現，一條訊息打字中（typewriter cursor 閃爍）
  • AI 回應逐字生成，同時右側 Canvas 出現對應內容
  • Token 計數器出現，數字動態增加（Odometer 效果）
  • Feature list 七項依序出現（左側欄 bullet stagger），搭配畫面對應功能亮起
  • 畫面 zoom-in 到 AgentPod 按鈕，作為下一段的引橋
Browser frame: border-radius 12px, shadow 0 20px 60px 0.4 Cursor: ease position, 1.2s per movement Typewriter: sourceText expression, char/frame = 1.5 Token counter: valueAtTime + easeOut, 3s UI panel stagger: 0.15s delay per panel

第三段 · 案例二 + 生態

AgentPod Service + Vertical Agent Apps + 生態夥伴

從使用者體驗層深入到基礎設施層，展示平台的技術能量與生態廣度。約 35–50 秒。
AgentPod Panel UI Multi-Runtime Node Graph Sandbox / Guardrail Vertical Apps AI Partner Ecosystem
腳本摘要與段落目的
AgentPod Service 功能列表 Diverse Multi-Runtime Selection · Instant Deployment & Execution
Dynamic Runtime & Model Orchestration
Secure Enterprise Sandbox Isolation
展示指示 AgentPod Panel 入口 → Launch → 多 model 選擇
Sandbox / Guardrail 警示 → Vertical Apps（IT/SRE/多場景）
生態夥伴：GPT-5.5 / Gemini 3.1 Pro / Claude Sonnet 4.6 / Claude Opus 4.7
段落目的
從「好用」升級到「強大」。這段要讓觀眾感受到 AgentPod 是一個真正的技術引擎，能同時調度多個 AI 模型、跨 Runtime 執行，同時保有企業級的安全控制。情感目標：敬畏感 + 技術可信度。
視覺基調再轉換
從 MyAgent 的「人性化 UI 感」轉向更技術性、工程感的視覺語言。Node graph、連接線、多節點並發——類比 AWS re:Invent 或 Kubernetes 視覺化圖表的風格。色調可以加入更多紫/青調，強調 AI infrastructure 的感覺。
Vertical Apps + 生態的處理
Vertical Apps 建議用卡片翻轉快速切換行業場景（IT → SRE → 法律 → 財務），每次翻轉 0.5s，不停留太久。生態夥伴（GPT/Gemini/Claude）作為收尾的高潮，用 bouncy logo reveal + Aurora 漸層做首尾呼應的 bookend 結構。
關鍵動畫時刻 · AE Keyframes
  • AgentPod Service 標題 + tagline，背景轉換為更深、更技術感的色調
  • AgentPod Panel UI 從畫面中央出現（與 MyAgent browser frame 相似但更工程感）
  • 游標點擊 Launch → 動態 loading ring 旋轉
  • 多個 Model badge（GPT / Claude / Gemini）從四方飛入中心，連接線 draw-on
  • 連接線帶流動光點（沿 path 的 position 動畫），模擬 token 流動
  • Sandbox 視覺化：邊框閃爍 → Guardrail 警示出現（shield icon 亮起）
  • Vertical Apps：卡片翻轉 × 3–4 次，快速展示不同行業場景
  • 生態夥伴 logo grid reveal（bouncy entrance, 0.12s stagger）
  • 最終 tagline「Built for Your Enterprise Agent」+ Aurora 從中心擴散收尾
Node graph: null parent + position ease per badge Flow dot: valueAtTime along Bezier path Sandbox border: opacity pulse 0.8→1, 0.4s loop Card flip: rotateY 0→180, backface hidden Logo bounce: Scale 0→115→100%, 0.35s Aurora finale: Gradient Ramp scale + opacity fade-out
