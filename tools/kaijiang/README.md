# 嘴型元件（開講試點）

把角色前視圖＋一段原音做成會說話的水墨頭像，輸出開講直式（9:16）與油管角落（16:9）兩種試片。全程本機運算，$0。任務脈絡見 `video-projects/kaijiang-pilot/BRIEF.md`。

## 需要的東西

- Python 3＋`pillow numpy pypinyin`（建議放 venv）
- 逐字時間碼：openai-whisper `small`，`word_timestamps=True`，輸出 `[{"w","s","e"}]` 的 `words.json`
- ffmpeg／ffprobe
- 角色前視圖：私有三視圖，不進 repo

## 執行

```bash
python engine.py <本目錄> <角色三視圖.png> words.json clip.wav clip.m4a <中文字型.ttf> <輸出前綴>
python mouths.py <角色三視圖.png> <聯絡表.png> <中文字型.ttf>   # 只出 6 種嘴型聯絡表
```

- `clip.wav`：16 kHz 單聲道，算音量包絡；`clip.m4a`：成片音軌。
- 輸出 `<前綴>-big-9x16.mp4` 與 `<前綴>-small-16x9.mp4`；`STILL=1` 只出姿勢聯絡表。

## 目前狀態（v9）

- v9（2026-10-29）：頭身分層。頭（嘴型、眨眼）取自前視圖，接縫在下巴下緣 y 698；身體換姿勢圖，6 種：垂手、攤手、手指、托腮、胸口、搔頭。
- 姿勢圖：`POSES=<資料夾>` 指定，檔名 `<姿勢>.png`，與前視圖同畫布 2400 × 1760；手會蓋到頭的另給 `<姿勢>_前.png`（透明，只畫手）。缺的姿勢自動退回垂手。
- 姿勢排程依逐字稿關鍵詞，同一姿勢至少 3 秒、任 10 秒最多切 2 次、交叉淡化 0.15 秒。`STILL=1` 出姿勢聯絡表；`POSE_DEBUG=1` 在畫面左下標姿勢名；`ONLY=big` 只出直式。

- v8（2026-10-29）：擦除框改 y 578–654，包住原圖下唇陰影；補色四邊調和內插，遮罩近硬邊。v7 的橫向色帶就是擦除框切半那筆陰影留下的。
- Windows：字型用 `C:/Windows/Fonts/msjhbd.ttc`；`words.json` 已明指 UTF-8 讀取。這台 PC 30 秒兩版約需 15 分鐘以上。

- 座標是老查三視圖（2400 × 1760）的實測值：嘴心 (490, 604)、眼睛 (400, 484)／(562, 484)。換阿分要重量座標。
- 6 種嘴型（閉、抿、小開、大開、扁、圓）全由程式重畫，線寬固定 8 px；嘴型由 `pypinyin` 韻母判斷。
- 動作：重音點頭、疑問詞歪頭、隨機眨眼、呼吸。
- 手臂切層擺動已移除：原圖手臂貼身體，切開會破圖。手勢改走姿勢圖。
- 去背用 flood fill 挖亮色紙底；輪廓線有缺口的圖會漏挖，換圖要逐張檢查。
