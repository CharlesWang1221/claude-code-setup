## 唯一來源分工

Google Drive 是私有素材與決策紀錄的唯一來源。repo 是規格、程式、任務控制檔與不含可識別人物的清單來源。兩者不互相覆蓋。

換到 Mac 後，Codex 仍需在 repo 執行 `git pull` 與 `./setup.sh` 才有相同 Skills；Google Drive 不會同步 Codex 的規則與工具設定。

## 建立位置

在既有 Google Drive 的 `不標準答案` 資料夾下建立：

```text
不標準答案/
  素材庫/
    剪紙風/
      角色舞台/
        00_管理/
          角色舞台素材庫_方向決策.md

        01_角色/

          小寶/

        03_物件與前景/
        04_鏡頭測試與 QC/

```

## 存放規則

| 類型 | 放置位置 | 是否進 repo |
| --- | --- | --- |
| 這次方向、鏡頭限制、驗收結果 | `00_管理/角色舞台素材庫_方向決策.md` | 去識別摘要可進 repo |
| 素材索引、標籤、可重用狀態 | `00_管理/asset-manifest.csv` | 欄位模板可進 repo；具體私有素材清單不上傳 |
| 角色參考、透明 PNG、PSD、原始工程 | 對應角色或舞台資料夾 | 不進 repo |
| proof、QC 抽格、鏡頭輸出 | `04_鏡頭測試與 QC/` | 最終驗收文字可進 repo；影像不進 repo |

## 使用流程

1. PC 或 Mac 開工前，先讀 `00_管理/角色舞台素材庫_方向決策.md` 和 `asset-manifest.csv`。
2. 優先重用已驗證素材。新增可泛用素材時，補齊 ID、透明圖層、錨點、標籤、來源與最後使用日。
3. 單集素材若含私人家庭資訊或只適用一次，不升級進主庫。
4. 每次同步後，讀回資料夾與檔案清單；未讀回前不得宣稱另一台電腦已可使用。
