# 剪紙社群影片模板

這是可重複使用的 8 秒物件動畫鏡頭，不是整張圖的推鏡。

素材分為背景地圖、衛星、地標與報紙；每個元件都有獨立的進場或停留動作。

## Render

```powershell
.\render-object-motion.ps1 -Caption '你的字幕文字' -OutputFile 'my-scene.mp4'
```

輸出為 1080 × 1920、30 fps、H.264 MP4。

## 已固定的動作節奏

1. 0.0 至 2.0 秒：衛星漂浮，路線依序畫出。
2. 2.2 至 3.0 秒：地標落下並回彈。
3. 3.3 至 4.2 秒：報紙滑入。
4. 4.2 至 8.0 秒：停留讓觀眾讀字幕。
