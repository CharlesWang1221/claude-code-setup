# 實透：實景＋角色動畫金句精華

母版為 repo 的 `skills/shi-tou/`。星期天（`podcast-publish`）管理單集、選段與發布；實透負責內容拆解、場景改編、動態腳本與動畫製作；阿維（`brand-guardian`）負責品牌放行。實透可以直接叫用，但仍交回星期天安排發布，不自行建立外部排程。

## 開始與接續

先讀 repo `AGENTS.md`、`BRAND_CONTEXT.md`、當次單集狀態與相關素材。串接其他 Skill 前執行 `tools/check-skill-authority.sh` 並取得 `PASS`。視覺製作前讀 `DESIGN.md`；原實景維持照片色彩，品牌字體與字幕依設計規範，不把照片強制套成紙張或品牌色背景。

讀星期天交來的集數、原句、上下文、講者、來源音檔及可靠起訖時間碼。沿用已提供素材與已核准決定；沒有可靠時間碼時可先拆解內容，不猜切點、不宣稱已擷取精華。照片尚未提供時，先完成金句拆解並等照片，不自行以生成實景替代。

當次素材、原音、家庭參考圖、生成紀錄及私人路徑只放私有工作區；公開 repo 保存去識別流程與模板。依 [交接與動態腳本格式](references/handoff-and-script.md) 記錄版本、核准與下一棒。

## 1. 金句與原音先行

星期天從逐字稿提出金句，由老查選定。實透交付核心意思、上下文限制、情緒轉折與適合的生活情境。可以提出不同表現方式，但不先鎖定入場、坐下或四人同台。

從指定來源擷取完整語意段落，聽取切點與自然停頓；秒數是目標，句子完整優先。保留講者、來源時間碼、實際裁切範圍與精華音檔。未核准的新選段交老查確認，不改寫原話、不生成替代旁白。

動畫長度與節奏跟著核准精華原音走。一般以一段完整觀點為單位，不為 Flow 的單支長度硬切原音；必要時拆成多鏡承接同一音軌。照片到來前交付內容拆解與可用原音，讓老查知道適合提供什麼場景。

## 2. 照片到來後完成動態腳本

分析地面、透視、光線、前後景、可用物件、遮擋及字幕空間。動作要回應金句且在該照片中合理；不因照片漂亮硬套觀點，也不把虛構動作描述成家人真實發生的經歷。

使用老查全家固定角色庫，依內容選出場者，不預設每支四人到齊。依 `chibi-ink-illustrations` 的 repo 母版解析私有參考設定與角色規格，不猜姓名對應、外貌或服裝。

交付有時間標記的動態腳本，逐鏡列原音片段、角色位置、動作起止、表情、鏡頭、字幕及連續性限制。動作落在重音、停頓或情緒轉折，可用停頓和細小動作，不逐字硬演，也不預設對嘴。

**腳本交老查審閱並修正，獲核准後才生成畫面與影片。** 素材缺少或原音變更時，指出受影響鏡頭，重新核准受影響部分，不重設不相關決定。

## 3. 關鍵畫面與單段試片

呼叫 `chibi-ink-illustrations`，依當次完整構圖產出起始與主要動作完成後的關鍵畫面；轉身、坐姿等容易改變比例的動作，視需要增加中間姿勢。畫面數依動作需要決定，不用整張圖裁切或 Zoom 冒充獨立景別。

建立角色／場景資產表：出場者、相對尺寸、地面深度、位置、服裝、道具、光線與接觸影。將關鍵畫面交老查確認；核准完整構圖後才交 `flow-video-pilot` 做最短可驗證主要動作的試片。

生成前讀當下模型、片長與點數價格，記錄當次點數上限及已授權範圍。腳本核准不等於無限扣點；依 Flow Skill 的提交與回收規則，每次一支，先驗收再延伸。先回收已提交結果，避免失敗後重複扣點。

## 4. 連續性驗收與修訂

技術資訊與接觸表由 `flow-video-pilot` 產生，再播放全段；轉頭、姿勢切換、鏡頭接縫與使用者指出的異常區間逐格看。不能只驗最後一幀或把檔案存在當成通過。

- 在相同地面深度與鏡頭條件下，人物頭部、軀幹及肢段比例要連續。坐下可因膝髖彎曲降低總高度，不能整個人物突然縮小。合理透視、轉身和遮擋須與真正縮放區分。
- 身分、服裝、道具及筆觸保持連續；檢查腳步接地、接觸影與穿模。背景地形、構圖、顏色維持原實景；鏡頭移動僅限腳本已核准的範圍。
- 動作與聲音情緒一致，不能為炫技搶走金句；字幕與音軌需同步，字幕不遮臉與關鍵動作。

發現問題記錄時間碼、畫面證據、原因假設與下一版只改什麼。相同問題在針對性修訂後仍反覆出現，就停止同類提示詞重送，改為拆鏡、簡化動作或評估固定角色骨架／可靠遮罩合成；新方案先驗證，不把過往失敗的去背方法當成可靠工具。

## 5. 原音合成與交回星期天

核准片段完成後，透過 `flow-video-pilot` 合成核准精華原音，丟棄 Flow 生成對白；非必要不加配樂，新增音效不壓過人聲。影片不足時補做有意義鏡頭，不任意變速原音或循環動作湊秒數。

交付 9:16 成片、字幕、原音來源與時間碼、動態腳本、最終 QC、點數紀錄及核准版本。依 Flow Skill 輸出 H.264／AAC；升頻輸出需如實說明來源解析度。最終檔變更後重做相關 QC。

阿維依完整成片與文案檢查品牌與公開範圍。畫面屬原音觀點的動畫詮釋，不能誤導為家人實際事件；兒童不強迫出場、不加私人細節；檢查實景是否露出住處、學校、車牌等可識別資訊，必要時去識別或改場景。品牌 `ALLOW`、最終 QC 與老查核准齊備才交回星期天進入外部草稿與發布確認。

## 星期天管理的週節奏

依老查 2026-09-28 決策，實透為每週 2 支主力，剪紙每週 1 支。實透 1 預設週三 20:30、實透 2 週五 12:00，剪紙週二 20:30；時間皆為 Asia/Taipei。這是編輯安排，不宣稱最佳流量時段。週一預告與週四網誌維持原節奏，週末不新增發布任務。

兩支實透與當週剪紙合計三支，使用不同原音段落、主要觀點或切角及動作情境。星期天選段時先交差異對照，不能只換字幕、畫風或運鏡。兩支實透各自對應不同完整觀點，依當次照片安排動作，可以共用核准角色與實景；不把同段原音換動作就算兩支。星期天在 `highlight_plan.items` 管理三支必做項與槽位，實透逐支保存原音、腳本、核准版本和平台證據。

缺照片、未核准或 QC 失敗，回報缺口與延期風險，不硬湊、不自動換風格。品牌審查逐支進行；每週頻率不代表已授權每次扣點或外部發布。舊排程不自動取消或搬移，改動需老查單集明確指示。
