# 短影片實驗檢視

短片不是一次性的靈感賭注，也不是由演算法決定價值的考試。這個流程要回答的只有一件事：哪一種入口，較能讓對的人願意停下來，並帶著一個自己的念頭離開。

## 開始前

1. 完整讀取根目錄 `AGENTS.md` 與 `BRAND_CONTEXT.md`。
2. 讀 `brand-guardian`，先完成內容的品牌放行；焦慮、比較、唯一解或未經同意的私人細節，不能拿來當測試變因。
3. 若短片源自 Podcast，讀 `podcast-publish`，只使用已核准的核心主張、原話與時間碼。一般預告、剪紙精華、真人短片仍各自依其原 Skill 製作。
4. 不重寫節目觀點以迎合數據。實驗只可改變「如何把觀眾帶進觀點」，不可偷換觀點本身。

## 檔案與週期

- Podcast 短片：建立或更新 `output/ep-{slug}/short-video-experiment.md`。
- 非 Podcast 短片：建立或更新 `output/short-video-experiments/{yyyy-mm}-{slug}.md`。
- 在建立草稿或排程前完成產前卡；發布後第 7 天完成驗證卡。跨片規則至少累積 4 支可比短片才討論，連續 3 次成立才可稱為「暫定規則」。
- 原始後台匯出、帳號資訊與可識別留言不提交公開 repo；檢視檔只留去識別的數字、短摘與結論。

## 產前假設卡

每支短片都要填。沒有基準也照樣填，但結果只能標記為待驗證。

```md
## {asset-id}｜產前假設卡

- 形式／平台／發布槽位：剪紙精華 1｜IG Reels、FB Reels、YouTube Shorts｜週三 20:30（Asia/Taipei）
- 不可改動的核心觀點：
- 來源依據：逐字稿原話／時間碼，或老查核准的原創內容
- 對象正在卡住的具體場景：
- 本次入口假設：
- 唯一測試變因：生活場景開頭／衝突判斷開頭／直接提問開頭（三選一，或明確寫另一項）
- 保持不變：核心觀點、素材段落、時長區間、發布槽位、CTA
- 預期的真實反應：收藏／分享／具體留言／導向正片，擇一
- 主要成效訊號：
- 次要診斷訊號：前 3 秒留存、完播、平均觀看、觸及、按讚
- 可比基準：同平台、同形式、同發布槽位的最近 4 支中位數；不足則寫「尚無基準」
- 品牌放行：ALLOW／REVISE／REJECTED，附檔案或日期
- 驗證日期：發布後第 7 天，Asia/Taipei
```

### 入口變因定義

一次只選一種，否則結果沒有解釋價值。

| 入口 | 用法 | 不可變成 |
| --- | --- | --- |
| 生活場景 | 從一個看得見的物件、對話或卡住瞬間進入 | 把家人或孩子私事做成鉤子 |
| 衝突判斷 | 用一個可被反駁、但有責任的立場進入 | 製造敵人、羞恥或恐慌 |
| 直接提問 | 問聽眾已經在心裡問自己的問題 | 假提問式的標準答案 |

如果這支片的完成任務是「測試剪紙字幕可讀性」或「修正聲畫」，不得同時宣稱在測內容入口。技術 QC 與內容實驗是兩張不同的表。

## 發布後驗證卡

先讀 `podcast-performance-review`。只使用老查提供的後台截圖、CSV 或已授權的讀取資料，不猜數字。

```md
## {asset-id}｜7 天驗證卡

- 資料完整度：完整／部分／缺少 {欄位}
- 可比基準：{樣本數} 支，同平台、同形式、同槽位

| 訊號 | 本支 | 基準中位數 | 差異 | 判讀 |
| --- | ---: | ---: | ---: | --- |
| 主要成效訊號 |  |  |  |  |
| 前 3 秒留存或等效訊號 |  |  |  |  |
| 完播或平均觀看 |  |  |  |  |
| 收藏／分享 |  |  |  |  |
| 具體留言 |  |  |  |  |
| 導向節目 |  |  |  |  |

- 觀眾原話：最多 3 則，去識別後保留其口語。
- 數據事實：
- 合理推測（不可寫成因果）：
- 品牌訊號：內容有沒有讓人更靠近自己的生活？有／沒有／資料不足。
- 判定：KEEP／ITERATE／STOP／UNRESOLVED
- 下一支只改的 1 件事：
```

### 判定規則

- `KEEP`：主要成效訊號優於可比基準，且留言、分享或收藏沒有顯示焦慮、誤解或過度承諾。不是代表公式已成立，只代表值得再驗證 1 次。
- `ITERATE`：入口有停留或互動訊號，但無法帶到預期反應。下一支只調整同一入口的措辭或場景，不換核心觀點。
- `STOP`：成效低於基準，或品牌放行後仍出現焦慮、比較、獵奇消費等明確負訊號。停止的是入口做法，不是題目或人。
- `UNRESOLVED`：資料不足、比較組不成立，或同時改了超過 1 個變因。不得硬下結論。

高觸及但沒有保存、分享、具體留言或導流，不得自動判為有效。低觸及但出現真實的「我也正在這樣」回應，必須保留為品牌訊號，不能被播放量蓋掉。

## 星期天的接點

當星期天製作一般預告與兩支剪紙精華時：

1. 先為每支短片建立產前假設卡，再進入各自的製作與 QC。
2. 一集最多指定 1 支為「內容入口實驗片」。另外兩支維持節目完整性，不為湊比較組而切斷語意或改動發布節奏。
3. 發布後第 7 天，將短片驗證卡併入該集的 `performance-review-7d.md`。下一集只帶走 1 個待驗證調整。
4. 未完成品牌放行、沒有產前假設卡，或沒有排程成功證據時，不得把影片標示為已進入實驗。

## 回報格式

每次只回報這 4 行：

```md
短片實驗狀態：產前已定義／待發布／待 7 天資料／已判定
本次測試：{唯一變因}
目前證據：{事實，不做推論}
下一步：{只改 1 件事，或等待資料}
```
