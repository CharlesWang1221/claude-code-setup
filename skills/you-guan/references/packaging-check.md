# 油管包裝與開頭承接檢查（2026-11-02 起）

每支油管長片在「正式渲染與包裝」階段、送鐵雄 QC 前，由製作者先跑一次本檢查並把結果寫進狀態檔 `packaging_check`。本檔只補「標題、縮圖、開頭承接」三件事的判準；起步期優先序仍以 [起步期規則](growth-stage.md) 為準，縮圖規格仍以 [Podcast 長片視覺](podcast-dialogue.md) 為準，品牌放行仍歸阿維。

來源：參考外部「影片封面標題承接檢查」方法改寫成本頻道版本；原方法是教學／工具類頻道用的，這裡已刪掉不適用的部分（人臉表情封面、悬念拖到片尾、強制 CTA）。

## 一、標題：問題句裡放一個對比

起步期標題先是觀眾會搜尋的問題句（growth-stage 第 1 條）。在問題句成立的前提下，只挑原音裡最強的一個對比放進去，不羅列整集內容。

| 對比類型 | 本頻道寫法範例（只示意結構，實際字詞取該集原話） | 適合題材 |
| --- | --- | --- |
| 付出與代價 | 「為了讓孩子贏在起跑點，我們付出了什麼？」 | 親子、教育、家庭分工 |
| 以為與實際 | 「以為存到退休金就安全，結果卡在哪裡？」 | 錢、制度、職涯 |
| 前後時間 | 「十年前跟現在，我們吵架的理由差在哪？」 | 夫妻、成長回顧 |
| 少與多 | 「一句話讓孩子不再頂嘴，為什麼其他方法都沒用？」 | 溝通、方法型 |
| 立場對撞 | 「老查跟阿分對這件事意見完全相反」 | 兩人辯論段 |

- 數字必須是原音或查證過的事實，交正風；不准為了對比自己造數字。
- 禁止標題黨：標題承諾的事，正片裡一定要有那段原音。說 A 播 B 直接退件。
- 句剪週標題的「為了⋯卻⋯」公式（`output/short-video-experiments/2026-10-title-formula.md`）可以借用，但長片標題仍以可搜尋問題句為主幹。

標題檢查（全部打勾才交）：

- [ ] 是觀眾會打進搜尋框的問題或關鍵詞，不是內部集數名
- [ ] 只放一個對比，不是「A、B、C 一次講完」
- [ ] 承諾的內容在正片有對應時間碼（寫進 `packaging_check.title_promise_at`）
- [ ] 手機寬度下前 25 個字就看得懂在問什麼

## 二、縮圖：一個焦點，能看懂結果或衝突

- 頻道還在起步期，角色臉不是品牌記號，縮圖主體優先放「這集的衝突或結果」：兩人立場相反的對峙構圖、前後對照、一個關鍵物件（帳單、成績單、時鐘）配角色反應。
- 畫面只留 1–2 個視覺焦點；主標 0–8 個字，比標題更短，不重複標題全文。
- 色彩、字體依 `DESIGN.md` 與 `podcast-dialogue.md`，每集同一套版位，讓觀眾在推薦欄認得出是同一個頻道。
- 禁用恐懼型視覺與擬真 AI 人物（見 growth-stage「畫面來源與停止線」）。

縮圖檢查：

- [ ] 縮成手機推薦欄大小（寬約 246 px）時，主標與焦點仍看得出來
- [ ] 縮圖跟標題講同一件事，但不是同一句話
- [ ] 沒有用正片第一幀或直式封面硬裁

## 三、開頭承接：前 60 秒確認承諾，答案不要拖到最後

長片觀眾點進來是為了標題那個問題。開頭沒提就滑走，太晚給答案也會滑走。

| 片長 | 開頭確認承諾 | 第一個實質答案或案例 | 收尾 |
| --- | --- | --- | --- |
| 10–15 分（B 單題圖解） | 前 30 秒 | 3 分鐘內 | 回到開頭那句原話或畫面 |
| 30–50 分（A 完整集） | 前 60 秒 | 5 分鐘內，章節第 2 段 | 停在具體場景，不做昇華總結 |

- 開頭 60 秒用原音剪出「這集要回答的問題＋一句最有衝突的原話」當冷開場，原音完整、不切斷句子；冷開場的原話必須在正片後段完整出現。
- 中段要有一個超出標題的收穫（一個沒預期的案例、一個孩子的原話），寫進章節名稱。
- 不加口頭 CTA 硬塞「記得按讚訂閱」；要提醒就由老查或阿分原音自然說，沒有就不加。

承接檢查：

- [ ] 前 60 秒內有標題問題的那段原音或字卡
- [ ] 第一個實質答案在上表時限內
- [ ] 冷開場原話在正片中有完整出處（記時間碼）
- [ ] 章節名稱至少一個寫出「中段收穫」

## 狀態檔欄位

```json
"packaging_check": {
  "title_contrast": "付出與代價",
  "title_promise_at": "00:12:34",
  "cold_open_source_at": "00:27:10",
  "first_answer_at": "00:04:20",
  "thumbnail_mobile_ok": true,
  "result": "PASS"
}
```

`result` 為 `REVISE` 時寫明哪一條沒過；鐵雄 QC 只核對欄位與證據，不替製作者補檢查。2027-01-28 起步期檢查點時，教父把各支的 `title_contrast` 與平均觀看時長並列回報，判斷哪種對比有效。
