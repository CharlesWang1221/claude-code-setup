# 油管：小查管理的 YouTube 長影片

repo `skills/you-guan/` 是唯一母版。老查交辦 YouTube 長影片時，由小查判讀任務、叫用油管、追蹤進度與驗收；製作總監負責品質，阿維負責品牌放行。油管是獨立 SOP，不代表背景常駐程序或已啟動的多代理。

## 接令與續作

讀 repo `AGENTS.md`、`BRAND_CONTEXT.md`、`DESIGN.md`、任務總表、當次專案規則與核准素材；串接其他 Skill 前取得 `tools/check-skill-authority.sh` 的 `PASS`。沿用既有 YouTube Task ID、BRIEF、HANDOFF 與核准資產，不因拆出流程重建或重做。

若屬 Podcast，可讀星期天已有的音檔、逐字稿、核准內容決策與圖像；共享素材不等於星期天必須製作長片或等它完成。非 Podcast 長片按當次原始素材與目的規劃，不強套全家或客廳版。

記錄來源、長度、講者／時間碼、目的、受眾、公開範圍及發布日期。只有「做長片」時先進製作，不擅自上傳；「上架」仍須通過品牌、最終 QC 與當次外部動作確認。長片獨立排期，不預設與 Podcast 週一 07:00 同步。

狀態與上傳工具的相容交接依 [獨立狀態與舊檔承接](references/state-and-upload.md)。私人原音、家庭參考、未公開資料與私人路徑不提交公開 repo。

## 製作流程

1. **判讀與建檔**：確認最小 BRIEF、素材清單、已完成版本與缺口。真人／訪談先依 repo 素材判讀規則提出建議，取得製作確認才轉 `shorts-pipeline` 或 `talking-head-recut` 等合適流程；不能把長訪談硬改成 Shorts。
2. **方案與時間軸**：依原音／素材規劃主張、段落、鏡頭、字幕與聲音。可靠講者時間碼決定切點；沒有時間碼先做構圖與節奏預覽，不假稱已對嘴。老查已選定形式與素材就沿用，不反覆問同一決定。
3. **資產與關鍵畫面**：建立角色／場景資產表，完成必要背景、獨立景別與片尾，讓老查確認。若是 Podcast 客廳對話版，讀 [Podcast 長片視覺](references/podcast-dialogue.md)；固定客廳母版、至少 3 張同鏡位主題背景、固定角色位置、核准特寫，背景只替換窗戶內容。
4. **代表段預覽**：先製作能驗證開場、主要切換與字幕的片段；發現比例、遮擋、說話者或鏡頭節奏錯誤先修資產。不用整張插圖縮放冒充獨立特寫，也不預設用單張封面撐完整長片。完成形式確認後才投入全片渲染。
5. **正式渲染與包裝**：按已核准完整時間軸輸出 16:9 長片，製作獨立 YouTube 縮圖、標題、說明、可靠時間碼章節與專屬片尾。縮圖與片尾不拿直式／方形硬裁。具體圖像與動畫工具依已選方案呼叫相應 Skill，不重寫其技術規則。
6. **驗收**：核對原音完整、影音同步、段落切點、每種背景／說話者特寫、字幕、角色邊界、片尾末段與影音編碼。交付最終檔、可播放預覽、QC 證據與待修時間碼。正式檔變更後重做相關 QC。
7. **上傳與排程交接**：品牌 `ALLOW`、最終 QC、老查成片核准及當次上傳／排程授權齊備後才操作。先讀回既有 videoId 與狀態，避免重傳；核對頻道、唯一正式 MP4、縮圖、文案、公開範圍與日期。上傳工具目前只上傳私人影片，不代表已排程或公開；Studio 排程需另外完成並讀回證據。

## 完成與管理界線

小查回報目前階段、最終版本、已通過／待核准項目、阻塞及下一步。沒有平台成功證據只能報待驗證；已有私人影片不因缺排程重傳一份。

星期天不產生 YouTube 長片、長片縮圖、章節說明，不執行長片渲染／上傳／排程，也不把長片未完成列為自己的阻塞。油管不可改寫星期天的 Firstory、IG、預告、實透、剪紙或 Shorts 狀態。原有 YouTube 任務與已排程／已公開內容保留，不自動取消、搬移或覆蓋。
