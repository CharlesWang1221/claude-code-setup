# 第四季交接檔名規則

狀態：ACTIVE。Owner：Claude Code 管理層維護，Codex 執行。生效：2026-11-14，Asia/Taipei。
來源：阿分 2026-11-10 指示第四季檔案統一命名，維總監整理成〈S4 檔名規則（給老查 AI 團隊）v0.1〉。原文在阿分那邊的 Drive，連結只放老查私人設定，不進公開 repo。

## 為什麼有這份

阿分那邊的 Claude 靠檔名找檔。檔名不照這套規則，對方就認不出是哪一集、哪個版本，交接會斷在檔名上。

S4E03 時，老查帳號的「ep3」同時指過長女病、一萬塊、寶可夢三集，阿分團隊只能逐檔聽內容判斷。這份規則就是為了不再發生這種事。

## 適用範圍

- **要套用**：上傳到阿分 Drive「01_不標準答案Podcast」各集資料夾的檔、交給阿分團隊的檔，以及老查 Drive 裡第四季的音檔、逐字稿、短影音和字幕稿。
- **不套用**：repo 和本機 `output/ep-{slug}/` 裡的工作檔。程式靠固定檔名讀檔，例如 `mon.json`、`.publish-status.json`、`*.timemap.json`、`*.passages.jsonl`。改了會讓工具找不到檔。
- 做法：本機照原本的檔名製作，**上傳或交件那一刻才改成本規則的檔名**，並把「本機路徑 → Drive 檔名」記進 `.publish-status.json` 或剪輯回報。

## 格式

```
S4E集數_集名_類型_版本_日期.副檔名
```

| 欄位 | 寫法 | 例子 |
| --- | --- | --- |
| 集數 | 對外集數，兩位數 | `S4E05` |
| 集名 | 照下方「集數對照」的固定寫法，一字不改 | `生不生` |
| 類型 | 照下方「類型」表 | `初剪音檔` |
| 版本 | `v1`、`v2`…；沒有版本的檔就省略這一欄 | `v2` |
| 日期 | 檔案建立日（台北），`YYYY-MM-DD` | `2026-11-09` |
| 副檔名 | 保留原本的，不重複 | `.mp3` |

其他寫法：

- 跨集檔寫 `S4E03-E05_長女病-生不生_…`，整季檔寫 `S4_全季_…`。
- 品管或複核紀錄接在被檢查的檔名後面，例如 `S4E03_長女病_上架包_v0.9_複核紀錄_v0.1_2026-11-09`。
- 舊版在檔名最前面加「（舊）」，作廢的加「（作廢）」。只改檔名，不刪檔。

## 類型

| 東西 | 類型寫法 |
| --- | --- |
| 錄音原檔，或只合併音軌、還沒剪的混音檔 | `未剪音檔` |
| 剪到一半的檔（照修剪清單剪完、還沒做後製） | `初剪音檔` |
| 上架用的成品 | `完成音檔` |
| 逐字稿（對應上面三種音檔） | `未剪逐字稿`／`初剪逐字稿`／`完成逐字稿` |
| 短影音（加星期與狀態） | `短影音_週一_候選`、`短影音_週一_重剪`、`短影音_週一_樣片`、`短影音_週一_上字幕` |
| 字幕校對稿 | `字幕校對` |
| 交接包、原音包資料夾 | `交接包`、`短片原音包` |
| 剪輯回報（Codex 剪完交件用） | `剪輯回報` |

- 逐字稿和它對應的音檔用同一個版號，例如 `完成音檔_v1` 配 `完成逐字稿_v1`。
- 短影音的星期照週計畫的槽位寫（週一至週六）。
- 表上沒有的類型（例如短影音封面），不要自己發明。先用 `短影音_週一_封面_v1` 這種暫定寫法交件，在回報裡標「類型暫定，待阿分團隊確認」。

## Codex 交件時的對照

照 `docs/briefs/PRE-PACKAGE-CUT-2026-11/BRIEF.md` 剪輯時，Drive 上的檔名一律這樣寫：

| 步驟產物 | Drive 檔名 |
| --- | --- |
| 時間碼母檔（只合併音軌） | `S4E06_一個人住_未剪音檔_2026-11-15.wav` |
| 未剪逐字稿 | `S4E06_一個人住_未剪逐字稿_2026-11-15.txt` |
| 照修剪清單剪完、還沒後製的母檔 | `S4E06_一個人住_初剪音檔_v1_2026-11-17.wav` |
| `podcast-audio-edit` 後製完的成品 MP3 | `S4E06_一個人住_完成音檔_v1_2026-11-17.mp3` |
| 對成品 MP3 重跑 Whisper 的逐字稿 | `S4E06_一個人住_完成逐字稿_v1_2026-11-17.txt` |
| 剪輯回報 | `S4E06_一個人住_剪輯回報_v1_2026-11-17.md` |
| 短影音成片 | `S4E06_一個人住_短影音_週一_上字幕_v1_2026-11-18.mp4` |

日期是示意。實際寫檔案建立當天的台北日期。

word-level JSON 是程式產物，只留本機，不上傳，也不改名。

## 舊檔改名

老查 Drive 裡第四季的舊檔（維總監 11-10 從共用權限看到約 72 份）要不要改名，等老查另開任務卡才做，Codex 不主動改。開工時照原文第五節：先逐份聽或讀前 2 分鐘確認集數，存對照表，再改檔名；不搬檔、不刪檔。程式產物、點開頭的系統暫存資料夾，以及垃圾桶裡的檔都不改。
