# 專案最小控制檔模板

任何新影片、長片、短片、網站、圖卡或跨平台內容專案，在建立程式碼、生成素材或渲染前，先複製本模板為該專案目錄的 `BRIEF.md`。它讓內容營運長有可管理的目標與終點，不取代專業 Skill 的完整 SOP。

```md
---
task_id: TASK-ID
status: ACTIVE
owner: 內容營運長／製作總監／品牌總監
created_at: YYYY-MM-DD HH:mm Asia/Taipei
last_updated: YYYY-MM-DD HH:mm Asia/Taipei
---

# 專案名稱

## 目標與完成定義

- 要解決的內容問題：
- 交付物：
- 輸出平台與比例：
- 完成的可驗證條件：

## 已決定的方向

- 受眾與一句承諾：
- 品牌或視覺限制：
- 已核准的原話、時間碼或來源：
- 不得做的事：

## 閘門與證據

- 必讀 Skill：
- 品牌放行：待檢查／ALLOW／REVISE／REJECTED。
- QC 要求：

## 目前狀態

- 狀態：ACTIVE／PENDING_APPROVAL／BLOCKED／REVISE／LOCKED／ARCHIVED。
- 已完成：
- 阻塞或待確認：
- 下一個動作、主責與 Asia/Taipei 時點：
```

沒有 Podcast 音檔、平台發布或跨日交接時，可刪除不適用欄位。不得刪掉「目標與完成定義」「目前狀態」「下一個動作」；這三項缺任一項，專案不能列為 `ACTIVE`。
