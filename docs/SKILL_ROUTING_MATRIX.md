# Skill 路由矩陣

本表是 CEO 的派工索引。Skill 名稱像部門名稱，不能只靠關鍵字硬配；先看交付物、素材型態、是否要對外發布與既有任務狀態。

| 任務結果 | 主責主管 | 優先 Skill／流程 | 最低輸入 | 停止線或替代路徑 |
| --- | --- | --- | --- | --- |
| 新集數從素材到跨平台發布 | 內容營運長 | `podcast-publish`（星期天） | 集數、音檔、逐字稿／時間碼、公開範圍 | 先讀品牌與各當下 Skill；未 `ALLOW`／無平台證據，不得發布 |
| 剪 Podcast 音檔 | 內容營運長＋製作總監 | `podcast-audio-edit` | 原始音檔、節目目的、可用逐字稿 | 未確認刪除範圍，不做破壞性覆蓋 |
| Podcast 一般預告 | 內容營運長＋製作總監 | `podcast-teaser-video` | 已放行主句、時間碼、音檔、視覺 | 句子要自然結束；未確認不渲染／不排程 |
| 剪紙節目精華 | 內容營運長＋製作總監 | `paper-collage-video` | 已放行金句、時間碼、最終音訊、角色規格 | Skill 為 `RED` 時先比對；QC 失敗不得建草稿 |
| 真人素材做 Shorts | 製作總監 | 先素材判讀，再 `shorts-pipeline` | 原始影片、音訊、可用逐字稿、發布目的 | 先向老查提出建議，取得「確認製作」才開始 |
| 訪談／對談長片重剪 | 製作總監 | 先素材判讀，再 `talking-head-recut` | 原始影片、逐字稿、想保留的對談連續性 | 不把訪談硬改成泛用 Shorts；需老查確認製作 |
| Podcast 表現與下集調整 | 成長與知識總監 | `podcast-performance-review` | 同觀察口徑的第 7／30 天數據 | 單集不升級為規則；缺原始數據就標不確定 |
| SEO 文章 | 成長與知識總監 | `seo-article-writer` | 核准主題或逐字稿、搜尋意圖 | 需品牌與事實檢查；完成稿依既定 Drive 規則落檔 |
| 留言轉選題與需求 | 成長與知識總監 | `voc-jtbd-demand-map` | 原始留言、討論串、客服紀錄 | 保留原話與來源，不把雜訊當市場結論 |
| 文章或數據查證 | 成長與知識總監 | `fact-checker` | 待查句子、原始來源或文章 | 找不到可靠來源就撤句或標未證實 |
| 品牌與對外文案放行 | 品牌總監 | `brand-guardian` | 完整文案／視覺、平台與公開範圍 | 非 `ALLOW` 就停；不得拿部分放行套用新版本 |
| 網誌主圖或分隔漫畫 | 品牌總監 | `blog-image-director` | 已定稿文章、發布位置、品牌需求 | 先提視覺敘事並等確認，再生成 |
| 角色水墨插圖 | 品牌總監＋製作總監 | `chibi-ink-illustrations` | 當次角色三視圖、人物／動作／位置 | 不寫入私人 reference 路徑；圖中文字後製 |
| 技術解釋型影片 | 製作總監 | `video-explainer`（影碩） | 可驗證主題、資料來源、目標觀眾 | 先判定是解釋型，不是純宣傳；必要時先等確認 |
| 情緒型品牌宣傳片 | 製作總監 | `video-promo`（影華） | 品牌目標、CTA、可用畫面 | 必須有明確 CTA 與品牌界線；不套用到常態 Podcast |
| 影片還在想「怎麼拍」 | 製作總監 | `animation-director`（阿諾） | 品牌傷口、受眾、目的 | 只產創意與分鏡，不直接算圖或寫 Remotion |
| 每日排程與例行報告 | 內容營運長 | `daily-routines-manager`（多利） | 排程名稱、目的、頻率、收件／落點 | 任何新增／變更外部排程須明確授權 |
| 工作站資料或流程 | 系統與資產總監 | Creator OS 專案脈絡 | 具體畫面、資料欄位或操作問題 | 先讀 `apps/creator-os` 規則；流程未驗證前不改程式 |

## 路由衝突裁決

- 標記「真人」或「訪談」時，素材類型優先於使用者口語關鍵字。先判讀，再請老查確認製作。
- 同時涉及「發布」與「影片製作」時，內容營運長管順序，製作總監管成片，品牌總監有放行權；CEO 協調，任何一方不得越過停止線。
- 需求不在表內時，CEO 不硬套 Skill。先判斷是討論、知識、視覺、影片、系統或外部操作，再提出最窄的適用流程。
